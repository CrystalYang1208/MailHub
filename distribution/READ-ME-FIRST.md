# 五分钟快速开始

1. 将Win11免安装运行包完整解压到有写入权限的目录，保留`wwwroot`。
2. 双击`运行演示.cmd`，在浏览器点“进入演示工作台”。无需任何真实邮箱账号。
3. 查看三账号统一收件箱，搜索“实习证明”，下载合成附件，写信给`receiver@example.invalid`。
4. 想展示异常：主题包含`[失败]`会保稿；包含`[未知]`会进入显式核对流程。只有合成模式有此开关。
5. 想测真实收发：关闭或保留演示窗口，运行`运行正式版.cmd`，创建新的本地用户，按QQ/163指引添加专用测试邮箱。授权码只在本机填写，不需要主力邮箱，不发给助手。

演示与正式数据目录互相隔离。刷新页面后需要重新运行启动器取得新的一次性链接；不要分享startup.json中的链接。

免安装包无须Node/npm/.NET SDK。源码包用于审阅和开发，需要README列出的工具。Win11程序由Linux交叉编译，DPAPI、Windows脚本及真实服务商仍需你在本机实测。

推荐明晚前先验证：演示包能启动 → QQ/163测试邮箱接入 → 发往受控收件端并核对 → 回复/已读/垃圾箱 → 最后检查交作业的包中没有`.local`或凭据。
