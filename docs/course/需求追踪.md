# 本轮需求追踪

有效范围由用户在2026-11-16确认：35条FR（24 Must / 11 Should）、五模板、Windows11。原Word的40条与Starter的35条不是同一版本，不混用编号。

## 编号映射

| 原40条版本 | 当前35条版本 | 说明 |
|---|---|---|
| FR-A07 | 取消 | 不修改显示名/同步范围 |
| FR-A08 / A09 / A10 | FR-A07 / A08 / A09 | 重授权 / 移除 / 启停 |
| FR-C08 | 取消 | 无会话合并 |
| FR-C09 | FR-C08 | 文件夹未读数 |
| FR-E03 / F04 / F05 | 取消 | 高亮 / 开机自启 / 配置迁移 |

35FR中FR-A02按用户确认补齐QQ、163、126、Gmail、Outlook五模板。原AC10引用旧FR-A09，对应当前FR-A08；原AC01～12判定语义保持。回复使用真实收到原邮件线程头，转发为独立引用邮件；没有会话合并UI。

## 验收边界

本轮实现与测试证据不等于正式验收。所有Must以及安全AC03/07/11需在目标平台和相应外部前提下通过，方能签发正式验收。具体已执行记录见验收记录.md；本机未测表见本机验收清单.md。

14NFR与10BR保留原指标；1000封检索合成测试证明本轮环境内的本地查询，不证明10Mbps真实200封同步≤30秒，也不证明Windows浏览器/DPAPI通过。
