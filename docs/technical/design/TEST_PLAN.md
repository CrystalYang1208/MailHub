## 关键集成补充

- 用户隔离：四用户分别写账号/头/正文/索引/草稿/附件；改URL/userId、旧session、切换中下载和旧worker写入均拒绝，索引绝不跨库。
- 密钥：改密提交前后崩溃分别只接受旧/新密码；不同user/account/keyId的AAD不能互换，刷新CAS与移除并发不复活账号；数据库损坏不覆盖空库。
- 同步：首次90天时区边界、空箱/稀疏UID/范围中expunge、固定上界后新入、完整FLAGS/删除扫描失败不删本地；UIDVALIDITY重建全量与旧worker守卫。
- 发送：HTTP同幂等键重复、不同payload冲突、RCPT拒绝禁止DATA、DATA确认丢失unknown、发送时退出及切用户、草稿附件引用直到对账结束。
- 缓存/文件：SQL账本拒绝漏淘汰提交；降低限额同事务；文件rename/DB提交间崩溃、磁盘不足/文件被占用不发布半附件；阅读淘汰不移除搜索命中。
